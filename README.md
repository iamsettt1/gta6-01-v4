**Puerto Alba — High Water** is a 2D top-down open-world crime game: a sun-soaked river-delta city in storm season, played as getaway driver Dana Ríos, working for fixer Celia Marín against the Aldana family syndicate. Twelve story missions run from a first courier job to a storm-season bridge heist with a helicopter escape. The city has eight named districts, a working harbour, an island joined by two bridges, and an airstrip. Drive ten car classes, ride a motorcycle, sail three boat classes, and steal a flyable police helicopter. A six-race street league, a tuning shop with neon underglow, three buyable safehouses, four weapons including a rifle, gang territory that recolours as you take it, taxi fares, export cars, sun-shell collectibles, a paint shop, and a five-star wanted system with police cars, roadblocks, police boats and a pursuit helicopter. Storm weather brings lightning, heavy rain and flooded streets. The HUD is oversized on purpose — a 340px minimap, 58px wanted stars and a 42px objective banner — so the game still reads at thumbnail size.

## Controls

- **WASD / arrows** — move, drive, fly (W/S for helicopter altitude)
- **E** — enter or exit a vehicle (steal cars, boats and helicopters)
- **Mouse + Click** — aim and shoot (drive-by while driving)
- **Shift** — sprint (stamina bar)
- **1–4** — pistol, scattergun, SMG, rifle
- **Esc** — pause · **M** — full-city map · **J** — missions board · **P** — phone
- **T** — fit neon underglow at the tuning shop · **B** — buy / rest at a safehouse (or bribe the police while wanted)
- **F** — shove a pedestrian · **G** — talk to a mission giver

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the game runs entirely from its own files, with no network requests. Screenshot scenes: `?shot=heli`, `?shot=race`, `?shot=rifle`, `?shot=garage` (with `&seed=N`).
